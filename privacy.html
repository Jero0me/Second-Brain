E.F.I. — Privacy

Enhanced Functional Intelligence · a personal dashboard used by its owner only · updated September 2026

E.F.I. is a private, single-user productivity dashboard. It is not offered to the public, and no data is sold, shared, or used for advertising.

Google data

When the owner connects a Google account, E.F.I. requests access to:

  • Google Calendar events and the calendar list — to show, create, move and delete events at the owner's request.
  • Google Tasks — to show and create tasks at the owner's request.

Calendar and task data is read directly by the owner's browser and is not stored on any server. The Google sign-in is kept as an encrypted, HttpOnly cookie on the owner's device and can be revoked at any time from E.F.I. settings ("Disconnect") or at myaccount.google.com/permissions.

E.F.I.'s use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

AI (Google Gemini)

When the owner asks E.F.I. something, the request and relevant dashboard context are sent to the Google Gemini API using the owner's own API key, which is stored only on the owner's device.

Dashboard data

Planner, finance, health and other dashboard data is stored in the owner's browser and synced between the owner's devices through a private Supabase database protected by sign-in and row-level security, so only the owner's account can read or write it.
