Connect Apple Health

No login here — the “Health Auto Export” iPhone app pushes your data to this dashboard. Set it up once and this page fills in on its own. Until then, energy uses default wake/bed times.
  1. Install Health Auto Export – JSON+CSV from the App Store.
  2. Create a REST API automation with URL —
  3. Add header Authorization: Bearer <HEALTH_IMPORT_SECRET> (the value set in Vercel).
  4. Include HRV, Resting Heart Rate, Respiratory Rate, Blood Oxygen, Active Energy, Step Count, Exercise Time, Sleep Analysis and Dietary Caffeine (+ Dietary Energy, Protein, Carbs, Fat for MyFitnessPal; optionally Dietary Water, Body Mass, Body Fat Percentage). Turn off “Aggregate data” for caffeine.
  5. Turn the automation on (e.g. every morning).
